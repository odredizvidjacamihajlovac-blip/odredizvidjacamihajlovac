# Sajt Odreda izviđača „Mihajlovac“ – izvidjacimihajlovac.com

Gotov sajt za GitHub Pages. Svi fajlovi su u jednom folderu, bez podfoldera, tako da se uvek otpreme zajedno.

## Postavljanje na GitHub
1. Raspakuj zip.
2. U repozitorijumu: **Add file → Upload files** → **choose your files** → označi **sve** fajlove (Ctrl+A) → Open → **Commit changes**.
3. Proveri da glavna strana repozitorijuma prikazuje `index.html`, `o-nama.html`, `aktivnosti.html` i sve `.webp` slike jedne pored drugih.
4. **Settings → Pages**: „Deploy from a branch“, `main`, `/ (root)` → Save.
5. Pod **Custom domain** upiši `izvidjacimihajlovac.com` → Save, pa uključi **Enforce HTTPS**.

Stare fajlove iz ranijih izvoza (npr. foldere `assets` i `js`) možeš da obrišeš; novi sajt ih ne koristi.
